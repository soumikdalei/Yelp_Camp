# YelpCamp

YelpCamp is a full-stack web application that allows users to discover, create, and review campgrounds. Users can sign up, add new campgrounds with images and descriptions, leave reviews, and interact with other campers.

## Features
- User authentication (signup/login/logout)
- Create, edit, and delete campgrounds
- Upload campground images
- Leave reviews on campgrounds
- View a map of all campgrounds
- Responsive design for mobile and desktop

## Tech Stack
- **Frontend:** HTML, CSS, Bootstrap, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose ODM)
- **Authentication:** Passport.js
- **Cloud Storage:** Cloudinary (for image uploads)
- **Geolocation API:** MapTiler (for displaying camp locations)
